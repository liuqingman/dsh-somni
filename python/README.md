# somni-memory

Python sidecar for [dsh-somni](https://github.com/liuqingman/dsh-somni) —
markdown + YAML front-matter memory store with hybrid recall, session-log
capture, and sleep-time (dream) consolidation. Pure standard library; the
vector layer (`pip install "somni-memory[embed]"`) is optional.

See the repository README for install and configuration.
