Brain-inspired design

照着大脑造记忆，不是把上下文拉长

上下文会满、会过期，还每轮都收费——它根本不是记忆，只是一块草稿纸。真正缺的不是「给模型更多字」，而是一套会自己整理、自己遗忘、自己想起的记忆。这事大脑已经解决了，所以我们直接抄它的机制。

双系统：直觉先到，推理后到

会话里记忆只读。最新的用户消息一进来，联想打分先跑一遍（System-1，阈值 0.52），够格就主动递一句，不够格就闭嘴——推理不被记忆占预算。同一条记忆一次会话只提示一次，像习惯化。

睡眠巩固：白天记流水，夜里长记性

整理搬进独立进程。全员 idle 才起 sleep.run，跑 ReAct 把当天日志蒸馏成知识、裁决冲突、淘汰噪声；任何 agent 复活立刻让路——人从不等待做梦。

突触衰减：不被想起就淡去

每条记忆带 score 与 stability，每次做梦复利衰减，被召回就加固——这就是间隔重复。跌到 0.2 移入归档，不删，但不再干扰判断。

联想扩散：想起一个，带出一串

召回不只靠字面匹配：关键词 + 向量余弦（bge-small）+ 沿 related: 链路一跳扩散（衰减 0.6）。像人一样顺着关联想起来，而不是精确查表。

白天：直觉递一句→ 全 idle：睡眠巩固→ 蒸馏 · 裁决 · 淘汰→ 醒来：只剩判断

仿生不等于黑箱：全部记忆落盘成带 front-matter 的 Markdown，能读、能改、能 grep、能进版本库。

Forgetting

记忆的根本不是存得多，是忘得对

所有记忆系统都在比赛能存多少。但真正拖垮 agent 的不是「不知道」，是知道得太多、太旧、太像——检索时一堆过期判断混进上下文，模型照着三个月前的结论干活。

所以 Somni 把「遗忘」当第一等公民：不是存不下才删，是主动、按价值、带节奏地减噪。存是本能，忘才是设计。

分数衰减：不用就淡

每条记忆带 score 与 stability。每次做梦按 daily_decay = 1 − base/(1 + stability×0.5) 复利衰减：越常被想起，曲线越平——间隔重复的老规律。

归档线：0.2 以下退场

跌破 0.2 不进检索、不占上下文，移入 archived/ 留底。不删，但不再参与判断——降噪而不失忆。

冲突裁决：新证据胜

同一事实两个版本互相矛盾时，以新证据覆盖旧结论，旧版进归档。避免「新旧并存 → 检索随机命中 → 行为自相矛盾」这个最隐蔽的坑。

分层速率：情景退得比语义快

情景记忆 base=0.25，语义 base=0.1；高重要度情景再乘 0.4 缓释。细节先淡、结论后淡，和人一样。

衰减实测曲线 · 90 天
语义 · 反复召回（半衰 41 天，95 天到归档） 语义 · 偶尔召回（半衰 17 天，39 天到归档） 语义 · 新建未用（半衰 10 天） 情景 · 没人再用（半衰 3.8 天，9 天到归档）
同一套公式，用得多的记忆活三个月，没人碰的九天后就退出判断面。系统不需要判断「什么重要」——被想起本身就是投票。
Memory model

像人一样分层的记忆

全部落盘为带 YAML front-matter 的 Markdown：能读、能改、能 grep、能进版本库。

Episodic · 情景

发生过什么。按时间线沉淀，带衰减与冲突裁决。

Semantic · 语义

事实与概念。稳定、可复用，冲突时以新证据覆盖旧结论。

Prospective · 前瞻

还没做的事。不随时间遗忘，完成才清除。

Procedural · 程序

怎么做。把重复成功的路径固化成技能。

Identity · 身份

我是谁。常驻系统提示，跨会话不漂移。

Dream · 做梦

空闲时把当天日志蒸馏成上面几层，顺带做信噪维护。

Quick start

零配置接入 Cordis

# 装插件
npm i dsh-somni

# 或直接克隆仓库
git clone https://github.com/liuqingman/dsh-somni.git
cd dsh-somni && ./install.sh

# 数据目录里就是你的记忆
ls ~/.somni/memory   # knowledge/ skill/ episode/ ...
